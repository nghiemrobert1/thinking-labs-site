# Thinking Labs — company marketing site

Thin MVP storefront for **Thinking Labs, Inc.** (educational CKD / cardio-kidney-metabolic twin dashboards).

This is **not** the CKD Twin application. The Twin demo lives separately (e.g. `ckd-twin`).

## Pages

- `/` — Home / mission
- `/product` — Twin dual dashboards (educational framing)
- `/how-it-works` — Patient → clinician → later validated AI
- `/safety` — Educational intent, FDA/TEMPO plain language, HIPAA/BAA
- `/about` — Company + clinical advisor note
- `/contact` — mailto placeholder + non-functional form

## Stack

Next.js App Router + TypeScript + Tailwind CSS.

## Local

```bash
npm install
npm run dev
```

## Deploy

Vercel (preferred). Domain TBD (`thinkinglabs.com` under review).

## Compliance tone

No clinical claims, cure language, pricing theater, or FDA-clearance implication. Doctor decides.
